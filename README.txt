原神 聖遺物スコア計算機 v1.10

入っているもの
index.html : GitHub Pages用。単体で手動計算・自動評価候補・PNG作成が使えます。
public/index.html : Cloudflare Workerで画面も配信する場合の同じ本体。
worker.js : UID取得の中継コード。
wrangler.jsonc : 中継と画面をまとめて公開する設定。

使い方
1. GitHub Pagesならindex.htmlを置きます。
2. UID取得には中継の設置が必要です。GitHub Pagesにはサーバ処理がないため、HTMLを置くだけではUID取得できません。
3. CloudflareアカウントでWorkersを使用し、フォルダ内で npx wrangler deploy を実行すると、画面と中継をまとめて公開できます（最初はログインが必要）。ここでは設置・外部公開は行っていません。利用条件・料金は設置時に確認してください。
4. GitHub Pagesの画面を使う場合は、「UID取得の接続設定」に設置したWorkerのhttps://...workers.devのURLを入力します。Worker自身の画面を使うなら空欄のままです。
5. 公開先がmuya-nakama.github.io以外ならwrangler.jsoncのALLOWED_ORIGINSを自分の公開元に変更します。複数はカンマ区切り（URL末尾に/は付けません）。
6. ゲーム内プロフィールで展示キャラの詳細を公開し、UIDを入力してください。取得できないキャラは手動追加できます。
7. 育成方針は自動候補です。複数の運用があるキャラは手動で変更してください。係数も調整可能です。
8. 結果画像を作成してPNG保存または共有します。UIDの掲載は初期状態でOFFです。

評価の範囲
・基本式は会心率×2＋会心ダメージ＋攻撃力％。
・HP％、防御力％、熟知、反応サポート、各種サポート、チャージ、会心のみへ切替。
・熟知の初期係数0.25を含む係数は当ツール独自の比較用設定です。
・キャラの既知の初期候補とメインステータスを参考に判定します。未登録キャラは仮判定と表示します。
・新キャラ名は任意入力できます。キャラ名データはEnkaNetwork/API-docsの取得時点のデータ。
・編成、武器、凸数、必要チャージ量、会心上限を踏まえた厳密な最適化は行いません。
・全所持キャラは取得できません。Enka.Networkから公開展示データだけを取得します。
・再取得時には同一UIDの以前の取得キャラを置き換える前に確認します。手動追加したキャラは保持します。
・ブラウザ内で保存。旧v1.00の入力は同じ公開先のブラウザなら初回に引継ぎ。
・画像は生成AIを使わず、入力値を正確に描画したPNGです。
