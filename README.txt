原神 聖遺物スコア計算機 v1.15

使い方
・GitHub Pagesの一番上のindex.htmlを差し替えます。
・中継URLは設定済み。Cloudflareは変更せず使えます。
・原神プロフィールでキャラクター詳細を公開し、UIDを入力して取得します。
・キャラ画像を選ぶと各聖遺物とスコアを表示します。
・「手動入力はこちら」で手動追加・編集の入力欄が開きます。
・各部位のサブステータスは選択式の最大4枠。同じ項目やメインと同じ項目は選べません。
・「結果画像を作成」でPNG保存・共有ができます。UID掲載は初期状態OFF。
・設定、入力、取得結果はこのブラウザに自動保存します。

v1.15 更新内容
・手動選択からお試し用・内部用IDを除外。コロンビーナ等の重複と炎神表示を解消。
・旅人は炎・水・風・氷・岩・雷・草の各元素を1つずつ選択（男女では分けない）。
・UID取得時も旅人の元素を表示し、既存の取得データから元素を引き継ぎ。

v1.14 更新内容
・UID取得画面と手動入力画面を切り替える方式に変更。
・手動入力ではUID取得欄・取得キャラを非表示。独立した手動キャラを編集。
・「UID取得の画面に戻る」で元の取得キャラへ戻る。双方のデータは保持。
・画面切替時に以前の結果画像を閉じ、キャラの取り違えを防止。

v1.13 更新内容
・Enkaの最新store/giデータからキャラID、名前、元素、アイコンを更新。
・兹白、イルーガ、ファルカ、ローエン、リンネア、プルーネ、オデット、アリョーシャ、ヴェスナ、ヴォジャニーツァ、ドール男女を登録。
・サンドローネの画像名をMarionetteNewに修正。保存済みの番号表示と画像も更新。
・新キャラの評価は引き続き仮判定。入力値・係数・手動指定画像は維持。

v1.12 更新内容
・キャラ選択を画像ボタンへ変更。選択中の名前は結果欄に表示。
・UID取得中心の画面。未取得の初期状態では入力欄を非表示。
・手動入力の開閉ボタン。取得済みデータを手動で修正する場合にも使用可能。
・サブステータスを選択リスト＋数値入力へ変更。重複やメインとの重複を防止。
・結果PNGにキャラアイコンを追加。ついていないステータスは表示しません。
・実際についている加点対象外ステータスは淡色で表示します。
・キャラ画像を取得できない場合は仮アイコン。「手動入力はこちら」から画像を指定できます。
・保存済みのサンドローネ、コロンビーナ、ニコの番号表示を名前へ修正。
・従来の入力・係数を引き継ぎます。旧入力に5項目以上ある場合は保持し、整理する案内を表示。
・中継の接続先を初期設定。ブラウザ保存済みの独自設定も保持。

ファイル
index.html : GitHub Pages用の本体（単体で使用）。
public/index.html : Workerの静的アセットで画面も配信する場合の同じ本体。
worker.js : UID中継。静的アセットがなくても使用できます。
wrangler.jsonc : Workerと画面をまとめて公開する場合の設定。

評価の範囲
・基本式は会心率×2＋会心ダメージ＋攻撃力％。
・HP、防御力、熟知、サポート等の育成方針に応じて評価項目を変更。
・未登録キャラはメインステータスによる仮判定。武器、編成、凸数からの厳密な最適化は行いません。
・異なる育成方針の点数をそのまま比較しないでください。
・全所持キャラは取得できません。Enka.Networkの公開展示装備を取得します。
・再取得はキャッシュ期限に従います。同じUIDの以前の取得分を置き換える前に確認します。
・キャラアイコンはEnka.Networkの画像を利用。一部新キャラは取得先に未登録です。
・結果画像は生成AIではなく、ブラウザのcanvasで入力値を描画します。
